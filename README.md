# سایت عاشقانه برای حمید جونم 💗

یک سایت استاتیک فارسی با HTML، CSS و JavaScript؛ مناسب انتشار رایگان روی GitHub Pages.

## فایل‌ها
- `index.html`: ساختار صفحه و متن‌ها
- `style.css`: ظاهر صورتی، واکنش‌گرا و انیمیشن‌ها
- `script.js`: تعاملات، بازی‌ها، کارت‌های دلیل دوست داشتن و شمارشگر

## اجرای محلی
1. پوشه را در VS Code باز کن.
2. فایل `index.html` را در مرورگر باز کن. برای تجربه بهتر می‌توانی از افزونه Live Server در VS Code استفاده کنی.

## انتشار رایگان روی GitHub Pages
1. وارد https://github.com شو و یک مخزن جدید (New repository) بساز؛ مثلاً `hamid-love-site`.
2. مخزن را Public انتخاب کن و Create repository را بزن.
3. در صفحه‌ی مخزن، `Add file` → `Upload files` را انتخاب کن.
4. خود فایل‌های `index.html`، `style.css`، `script.js` و `README.md` را آپلود کن؛ بهتر است این فایل‌ها در ریشه‌ی مخزن باشند، نه داخل یک پوشه‌ی اضافی.
5. روی `Commit changes` بزن.
6. وارد `Settings` → `Pages` شو.
7. در قسمت Build and deployment، گزینه‌ی `Deploy from a branch` را انتخاب کن.
8. Branch را روی `main` و پوشه را روی `/(root)` قرار بده و Save را بزن.
9. کمی صبر کن؛ آدرس سایت در همان بخش Pages نمایش داده می‌شود. معمولاً شبیه این است:
   `https://USERNAME.github.io/hamid-love-site/`
   به‌جای `USERNAME` نام کاربری GitHub خودت قرار می‌گیرد.

## شخصی‌سازی
- متن نامه و اسم‌ها را در `index.html` تغییر بده.
- رنگ‌ها و ظاهر را از ابتدای `style.css`، در بخش `:root` تغییر بده.
- پیام‌ها و رفتار دکمه‌ها در `script.js` هستند.
- تاریخ رابطه در مرورگر بازدیدکننده ذخیره می‌شود و برای هر مرورگر جداست.

## نکته‌ی حریم خصوصی
این پروژه بک‌اند یا پایگاه داده ندارد. هر چیزی که در فایل‌های HTML/JS بنویسی برای بازدیدکننده‌ها قابل مشاهده است؛ رمز واقعی، اطلاعات خصوصی یا چیزی که نمی‌خواهی عمومی شود را در کد قرار نده. اگر مخزن Public باشد، فایل‌هایش عمومی‌اند.
